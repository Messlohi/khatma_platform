# Project Brief: Khatma Platform

## Overview

A multi-tenant Quran Khatma (Quran completion) management platform that combines Telegram bot and web interfaces for organizing collective Quran reading among families and groups.

## Core Functionality

- **Multi-Tenant System**: Support multiple independent Khatmas ( Quran reading circles) with separate tracking
- **Hizb Tracking**: Manage 60 hizbs (1/60th of Quran) - users can reserve, return, and mark as completed
- **Dual Interfaces**:
  - Telegram Bot for real-time notifications and commands
  - Web Dashboard for visual tracking and management
- **Family-Oriented**: Built for family-based reading circles with intentions (niyyah) dedicated to deceased relatives

## Target Users

- Families organizing collective Quran reading
- Community groups tracking Quran completion
- Individuals managing multiple Khatmas

## Key Features

- Reserve and track hizb assignments
- Mark completed readings
- View Khatma status and progress
- Admin management of Khatmas
- Developer dashboard for system-wide analytics
- Multi-language support (Arabic primary)
